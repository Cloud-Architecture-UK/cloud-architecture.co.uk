## ISO 27001 and NIS2

The guides don't cite ISO 27001 or NIS2 clause by clause, because the control sets overlap: the same CIS and NIST work above is what an ISO 27001 audit expects to see as technical evidence (Annex A), and it supports the Article 21 risk-management measures NIS2 requires. The [Frameworks page](/frameworks) explains how each one maps. Do the work once, evidence it everywhere.
