## Azure platform baselines

The table above is Microsoft 365. The Azure guides map to the platform equivalents: the **CIS Microsoft Azure Foundations Benchmark**, the **Microsoft cloud security benchmark (MCSB)** that drives Defender for Cloud, and the NCSC's **14 Cloud Security Principles**. Same idea — each control cites the specific recommendation it satisfies.

## UK regulated sectors

If you're in a regulated UK sector, the CAF work above carries most of the weight:

- **Health and social care** — the **NHS Data Security and Protection Toolkit (DSPT)** now maps to the NCSC CAF, so the CAF outcomes here line up with it.
- **Financial services** — the identity, logging and incident-response controls evidence the **FCA/PRA operational-resilience** expectations (SYSC), and **DORA** for firms with EU exposure.
- **Government** — **GovAssure** assesses departments against the CAF, which is exactly what this maps to.

## Beyond CIS and NIST

The guides don't cite ISO 27001, NIS2 or the other international standards clause by clause, because the control sets overlap. The same work is the technical evidence an **ISO 27001** audit expects (Annex A), it supports the **NIS2** Article 21 measures, and it lines up with **CISA SCuBA** (the US Microsoft 365 baselines) and the **ACSC Essential Eight**. The [Frameworks page](/frameworks) explains how each one maps. Do the work once, evidence it everywhere.
